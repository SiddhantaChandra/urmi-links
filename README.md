# urmi-links

A minimal, single-route link-in-bio page for content creator and writer [Urmi Chakraborty](https://www.urmichakraborty.com) ([@uwummie](https://www.instagram.com/uwummie)).

Live: [links.urmichakraborty.com](https://links.urmichakraborty.com)

## Overview

A clean, distraction-free landing page connecting verified channels — media kit, YouTube, Instagram, published articles, and contact. Designed with an editorial cream and burgundy palette, local typography, and lightweight client tools with zero UI framework overhead.

## Tech Stack

- **Framework:** Next.js 16 (App Router), React 19, TypeScript
- **Styling:** Vanilla CSS with custom properties & SVG noise overlay
- **Fonts:** Cormorant Garamond, Noto Serif JP, Plus Jakarta Sans (self-hosted)
- **Icons & QR:** `pixelarticons`, `lucide-react`, `qrcode.react`

## Getting Started

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the page.
